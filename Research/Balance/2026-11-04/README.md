# 중립 19종 실제값과 실게임 규모 제안

기존 게임값을 변경하지 않은 검토안이다. NeutralStats.html에서 “실게임 규모 제안 불러오기”를 누르면 실제 배치 기준과 전투 중 재생 0 계산으로 전환된다. 원래 HP1200 초안도 별도로 보존한다.

- 설계표 34축의 원종·유니크 계보 510쌍은 역전 0이다. 실제 게임 5축의 종간 비교는 855쌍 중 588쌍이 동률이거나 설계 순서와 다르다. 실제 중립은 모두 HP100/기본 공속0.8/자기재생0이며 공격·방어는 전투력에서 나온다. 설계표를 실제 게임 수치가 이미 적용된 것으로 보아서는 안 된다.
- 레벨4 보드 91칸에서 grade-g DNA는 g개의 새 내부칸을 필요로 하므로 grade 합은 90 이하다. 이 보수적 증명 상한은 HP910/방어90/재생8.8이다. 원래 초안의 4200/172/19는 이를 넘는다. HP1200 기준 유닛도 현 DNA로 생산할 수 없는 가상 기준이다.
- 탐색으로 찾은 실제 유효 배치 하한은 HP600/공격54/공속2.9/방어45/재생4이다. 최적해라고 주장하지 않는다. 새 제안의 각 최고값 590/53/1.12/44/1.9는 각 검증 배치보다 엄격히 낮다.
- 실제 엔진의 DNA 재생은 전투 종료 5초 뒤에만 작동한다. 새 제안은 전투 중 재생0, 재생 곡선은 전투 후 회복값이다. 정수 재생으로 19개 순위를 만들면 최소0~18이어서 현 단위의 DNA 상한8.8에 들어갈 수 없다. 검토기 재생 정밀도를 실제 DNA와 같은0.1HP/s로 확장했다. 다른4축 순위와 기존 초안 값은 보존했다.
- 새 기준은 유효한 레벨4 DNA51조각(체력49/칼날1/공격강화1), 262P, HP500/공격6/공속0.5/방어0이다. 시작 유닛이나 초반 경제 기준을 뜻하지 않는다. 정확한 배치와 원본 해시는 audit.json에 있다.
- 고정N으로 실제 server/combat.mjs를 사용한 19종 비교는 모두10.3~48.3초에 처치했다. 공속·타격 이산 시점과 전투 중 사망도 계산했다. 정적 시간 범위는10.2~47.2초다. 파생 DPS의 계보 서열 역전도0이다. 흰발>가시등우두머리, 걸어가는산>흰발은 별도1:1에서도 확인했다. 전체19종의 종합 전투력 서열이나 모든 실제 월드 전투를 검증한 것은 아니다.
