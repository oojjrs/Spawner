# 칼날+갑각 런타임 통합 검수 (2026-11-07)

## 적용 범위

- 새싹콩, 포자버섯, 몽돌, 샘방울의 대기·이동·근접 공격·피격·탄생·사망 24개 전신 애니메이션을 게임, 전투 실험실, 웰컴 헤더의 공통 렌더러에 등록했다.
- 원거리 공격은 등록하지 않았다. 정확한 칼날+갑각 외형(mask 03)에만 적용하며, 분비·발·더듬이 또는 이전 기관이 더해진 조합은 기존 외형 우선순위를 유지한다. 능력치와 저장 데이터는 변경하지 않는다.
- 전체 탄생 장면은 자체 둥지와 이동을 포함한다. 마지막 몸체의 접지점과 크기로 등록하고 외부 이동을 중복 적용하지 않는다. 사망은 마지막 프레임을 유지한다.
- 전투 실험실은 네 플레이어 종족에서 ‘DNA 외형 → 칼날+갑각’을 선택할 수 있다. 실제 카탈로그의 유효한 두 DNA 조각을 사용하며 중립 생물은 기본 외형만 허용한다.
- 기획서의 네 종족 조합 행과 24개 미리보기는 유지하고, 통합 적용 범위와 원거리 제외를 명시했다.
- 원본 시트는 기존 publication-manifest.json의 SHA256과 정확히 일치한다. 초상은 대기 첫 셀의 무변형 추출이다. 등록은 scripts/register-blade-carapace.py로 재현한다.

## 검증

- 게임 및 Combat.html 빌드 성공, 이미지 감사 1,106개 통과, git diff --check 통과.
- 조합 전용·공통 동작·웰컴·실험실·배포 묶음 집중 테스트 40개 통과. 별도 외형 아카이브 테스트 4개 통과.
- 정확한 mask 03 경계(4종족 × 32마스크), 스냅샷/DNA/이전 기관, 여섯 동작, 운반 이동 대체, 원거리 없음, 피격 우선순위, 탄생 접지, 초상, 웰컴 순환과 실제 실험실 DNA를 검증했다.
- 브라우저: 공통 렌더러 24/24 로드·좌우 반전·마지막 프레임, 기획서 탄생 확대, 실험실 네 종족 선택·근접 전투·사망 및 중립 종족 조합 비활성화를 확인했다. 게임 입장/웰컴 헤더도 로드했다.
- 전체 저장소 테스트는 완전 통과 상태가 아니다. 제한 실행에서 1,734개 중 1,322개 통과, 411개 실패, 1개 취소였다. 기존 HEAD의 오래된 모의 객체·폐기된 합성 방식·밸런스/문서 기대값 실패와 비교했다. 발견한 새 외형 개수 기대값은 수정 후 재검증했다. cheats 테스트의 동기 정지와 world 테스트 시간 초과로 전체 실행 완료는 확인하지 못했다.
