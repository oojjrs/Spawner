## 반영

- DNA 군락의 회복 예비금은 실제 기본 채집 DNA 생산비를 사용한다. 기존 슬롯 설계 군락은 기존 방식을 유지한다.

- 자동 DNA 생산과 사용하지 않는 자동 설계의 유효성을 추가 확인한다. 최신 설계 식별 및 둥지 수비 모드는 유지한다.
- 기존 AI 다중 시드 진단 명령을 최신 생산·전략 API에 맞춘다. 유료 공개 명령만 사용하며, 승리는 멸망으로 집계하지 않는다.
- 기존 게시 사후 기록, 자원 표시, 기획 미리보기, 런타임을 동기화한다.

- 옛 생산 테스트 기대값은 현행 정책을 유지한다. 승리 검사에서 기본 채집 DNA 회복비를 3P가 아닌 실제 11P로 정정한 보관 변경은 반영했다. 폐기된 API를 쓰는 미추적 시험 2개는 복구용 압축본으로 보존했다.
