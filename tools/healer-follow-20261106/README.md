# 치유지원 동선 검증 및 후퇴 대상 제외

## 확인 결과

- 시야1~2인 순수 치유 유닛이 2칸 밖 부상 아군을 찾지 못하는 것은 현 안테나 시야 제한의 결과다. 접근 범위를 임의 확대하지 않았다.
- 치유거리2 안에서 정지하는 것은 정상이다. 실제 게임 tick에서 2칸 거리의 아군 HP50→51을 확인했다.
- 실제 결함: 지원 이동은 후퇴 아군도 선택하지만 실제 치유 배분은 후퇴 아군을 제외한다. 가까운 저체력 후퇴 아군 때문에 멈춰, 시야 안 3칸 거리의 치유 가능한 아군을 향해 움직이지 않는 경우를 재현했다.

## 수정 및 검증

`server/game.mjs` 지원대상 필터에 후퇴 아군 제외 조건만 추가했다. 안테나 시야·치유거리·치유량·주기·후퇴 정책은 그대로다.

- 기존 코드 첫 회귀 실패: x50에 정지(예상 x51).
- 수정본 회귀3건 통과: 후퇴 아군 건너뛰기, 시야 밖 추적 금지, 치유거리 안 정지/회복.
- DNA·기절·복원 포함 관련17검사 통과.
- 이 수정이 중반 치유량 저조 전체를 해결했다는 의미는 아니다. 실제 브라우저·장기 시뮬레이션은 미검증.
- 직접 커밋·푸시·배포하지 않았으며 게시 담당에게 인계했다.
