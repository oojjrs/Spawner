# 몽돌 분비물+갑각 두 형태 좌향 원본 정규화

대상: pebble/secretion-carapace, pebble/secretion-carapace-antenna.

두 형태의 뒤껍질은 원본에서 왼쪽, 노출된 얼굴은 오른쪽에 있어 우향 몸통으로 확인했다. 공격 효과 방향만으로 판정하지 않았다. 대기·이동·원거리·피격·탄생·사망과 초상을 원본 셀별로 정확 반전했다. 후반 사망 파편은 방향 판정 대상이 아니며, 탄생의 회전 중간 자세도 정상적인 회전이다.

첫 검증은 25개 원본/동일 복사본과 21개 미리보기였다. 당시 누락됐던 안테나형 raw가 단일 원본 폴더 통합 후 발견되어, raw 6개와 탄생 시트 2개·미리보기 3개를 추가 완료했다. `deferred.json` 및 `raw-source-search.json`은 발견 전 이력을 보존한 자료이며 현재 미완료 상태가 아니다. 복구와 최종 결과는 `raw-changes.json` 및 `raw-metadata-changes.json`이 우선한다.

raw의 실제 셀 폭은 444/443/443/444, 높이는 444/443이다. 이 경계를 보존해 각 셀만 반전했다. 반전된 raw에서 프레임별 crop·translation을 사용하여 48개 packed 프레임이 정확히 재현되는 것을 확인했고 기존 pack.py 재실행 시 packed 바이트도 동일함을 검증했다. 공개 시트·manifest·피벗·bounds·원본 SHA·기획 미리보기는 같은 방향을 따른다. 게임에서 오른쪽 상대를 향하는 동적 반전은 유지한다.

새 방향이나 재작업이 불명확한 다른 몽돌 형태를 이 결과로 완료 판정하지 않는다.
