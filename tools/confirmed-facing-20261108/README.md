# 복합 외형 방향 교정 검증

범위: 사용자가 직접 반전을 요청한 새싹콩 `칼날+갑각+안테나`, `칼날+분비+갑각+안테나`의 전 동작 원본과 기획서 미리보기를 같은 기준으로 반전했다. 몽돌 분비 단일형은 픽셀을 바꾸지 않고 잘못된 right 등록만 left로 정합화했다. 상대를 향하는 공용 렌더 방향 로직은 변경하지 않았다.

- 새싹콩 원본·별칭 52개는 셀 순서·RGBA·알파·크기를 보존한 셀별 좌우 반전이다. 미리보기 28개도 시간·루프를 보존한다.
- 공유 탄생 레이어는 내용 기반 경로로 분리했다. 비선택 공유 원본 3개와 다른 42조합 등록은 그대로다.
- 피벗·탄생 레이어 좌표, 기획서 탄생 데이터, 승인 워크시트·원화 및 오프라인 래퍼를 함께 갱신했다.
- 전 44조합 시각 검수에서 위 두 사용자 지정 형태 외 추가 우향 확정 대상은 없었다. 새싹콩 갑각 관련 5형태, 포자 분비계 3형태, 몽돌 갑각 없는 4형태는 정면성이 강하거나 단서가 상충하여 임의 반전하지 않았다.
- 일부 새싹콩 공격 중간 셀의 칼끝/몸 기울임은 반전 후 오른쪽으로 보일 수 있다. 정확한 픽셀 반전 증명과 예술적 얼굴 방향 판정은 구분한다. 사용자 비교 자료는 대기·이동·근접/원거리·입퇴장을 함께 제시했다.

검증:
- `source-regression.txt`: 13/13 통과. Git 불변 원본 대비 244파일·7,494셀 독립 RGBA 검사, 보호 파일 58개, 752 route draw와 held 264 draw 포함. 큰 WebP를 두 장 동시 디코드하지 않도록 파일별·한 장씩 검사한다.
- `focused-no-heavy.txt`: 63/63 통과. 게임·전투 실험실 등록, 오프라인 픽셀 래퍼, 탄생 종료→대기 및 승인 이동 시계 포함.
- `bean-native-combined-summary.json`: 두 새싹콩과 몽돌 분비의 실제 Canvas 287 draw. 첫·중·끝, 탄생 레이어 실패 대체, 탄생→대기, 좌우 상대 및 웰컴/월드 일치.
- 기존 몽돌 전체 프레임 일괄 Canvas 검사는 메모리 한도로 종료됐다. 별도 제한 메모리 검증 결과와 혼동하지 않는다.
- 몽돌 12형태 추가 실제 경로 검수 144 draw, 웰컴/월드 48쌍 RGBA 완전 일치. 포자·샘방울 22조합은 510 draw의 크롭·좌우 변환과 실제 픽셀 시트로 재검수했다. 브라우저 스크린샷은 아니다.

미완성 AI 밸런스 작업은 이 변경에 포함하지 않는다. 공용 생성물은 해당 아트 모듈만 따로 반영하며 배포는 하지 않는다.
