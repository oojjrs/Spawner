# 근접 기절 중 치유 차단

사용자 2026-11-06 요청: 메모리의 남은 로직 작업 진행. 배포·푸시는 요청되지 않았다.

## 재현 및 수정

실제 근접 DNA 공격으로 치유 유닛을 0.1~0.6초 동안 기절시킨 뒤 0.2초 치유 주기에 아군 체력이 50→51로 증가했다. `updateDnaActions`가 원거리 기절 시계만 확인하고 근접 기절 시계를 무시했다.

치유·원거리 행동 진입 조건에서 두 시계 중 늦은 종료시각을 사용한다. 기절 중 치유 쿨다운은 소비하지 않으며 정확한 종료시각부터 정상 재개한다. 기존 근접/원거리 판정·수치·효과 자산은 변경하지 않았다.

## 검증

- 수정 전 신규 재현 검사 실패 (예상 체력50, 실제51).
- 수정 후 새 회귀2건 포함 전투·DNA·투사체·저장복원 관련97건 통과.
- 중첩 기절의 원거리 종료시각이 근접보다 빠른 경우와 늦은 경우 모두 검증.
- 실제 브라우저 실행은 미검증. 공개 배포·커밋·푸시 없음.
