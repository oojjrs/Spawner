# Welcome hold and display balance

- Every identity stays in the middle for a total of 1,500 ms. The old full idle cycle plus an additional 2,000 ms rest is removed. Asset preparation, pause/resume, overlap, and reduced-motion behavior remain intact.
- Welcome-only display sizes retain species order while compressing the game size spread to 25%. The cell used for travel and drawing changes together, preserving body-relative stride. No gameplay stats, source art, facing metadata, or per-frame scaling is changed in this patch.
- Nine relevant test files pass all 89 tests, including exact native-header 1.5-second transitions across playable and neutral identities, lifecycle recovery, source/runtime parity, presentation, direction transforms, and native turtle timing. Syntax and whitespace checks pass. This is not an all-repository test result.
- Real Canvas rasterization of all 87 appearances (68 playable forms and 19 neutral species), idle/enter/exit at five times each, yields nonempty images with no draw warnings. At 480×280, reference idle longest dimensions now span 58–80 px instead of approximately 50–139 px. All playable sampled idle poses span 57–75 px. Native canvas uses the production header draw function and presentation code; DOM/image scheduling and irrelevant tribe preload are replaced by a test harness. This is not browser playback.
- White-paw and shadow-weasel detailed entry/exit samples produce 16/16 distinct normalized images each at 80 ms intervals. This establishes frame changes, not natural gait quality. Small foot movement can still look like sliding; source gait work is tracked separately. Direction correctness is not certified by these pixel-size tests.
