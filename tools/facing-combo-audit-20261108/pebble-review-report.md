# 몽돌 칼날+안테나 화면 방향 후속 수정

사용자의 화면 기준 좌향 지시에 따라, 대기 0–7·걷기 0–7에서 얼굴과 몸 앞쪽이 화면 오른쪽으로 열리는 `pebble/blade-antenna`를 수정했다. 무기 타격 방향은 얼굴 방향의 유일한 근거로 사용하지 않았다.

- 추적된 원본/별칭 이미지 14개와 시간형 미리보기 12개를 정확 반전.
- 대기·걷기·공격·피격·탄생·사망 전체 형태, portrait와 reference 일관성 유지.
- 피벗·출구 좌표 반영, 프레임 순서·격자·시간·투명도 유지.
- 해당 탄생은 독립 full-scene atlas이며 공유 layer가 없다.
- 기존 기획서 링크는 반영한 동일 경로를 사용하고 scene metadata가 없어 추가 HTML 수정 불필요.
- 미추적 기존 파일 16개는 모두 해시 일치로 보존했다.
- 나머지 67개 전체 runtime 형태는 이번 변경 전과 동일하다.

## 검증

- 일반 게임·전투 실험실 빌드 완료. 선택 antenna art module만 기존 사용자 번들과 commit용 HEAD 번들에 각각 병합.
- 관련 9개 테스트 파일 74/74 통과, skip 0. 여기에 세 형태 원본/preview SHA 검증, 44개 기획서 조합 방향, runtime 및 전투 실험실 등록/그리기 검증이 포함된다.
- 별도 fast native/metadata 검사도 통과했다. 과거 전체 heavy pixel suite는 이번에 다시 실행하지 않았다.
- Chromium은 실행 환경 socket 제한으로 페이지를 시작하지 못했다. 실제 브라우저 화면 캡처 검증을 했다고 주장하지 않는다.

## 전수검수 결론

4종족×11복합=44형태의 원본·기획서 참조·동작을 점검했다. 확정 표시 오류 42칸과 연결 경로 오류를 먼저 수정했으며, 사용자 선택 새싹콩 2형태와 명확 우향 몽돌 1형태의 실제 원본을 반전했다.

나머지 새싹콩 9형태, 홀씨팡·샘방울 각 11형태는 정면 또는 얼굴 방향 판단이 불명확하여 임의 반전하지 않았다. 다른 몽돌 10형태 중 6개는 기존 방향을 유지하고 4개는 정면/혼합 단서로 분류했다. 나머지 41개가 모두 명백 좌향이라는 판정은 하지 않는다.
