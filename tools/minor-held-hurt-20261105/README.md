# 기존 원화 기반 피격 자료

안테나/발6형태. 현재 부속지 합성기에서 캡처한 참조원본6개를 보존한다. 사용자가 승인한0.5초 유지와0.38초 복귀를 적용한 제품 자료이며, 판정·이동·공격 시계는 변경하지 않는다.

이 폴더에는 제품 metadata와 회귀 검사에서 참조하는 원본/검증기록만 선별 보존했다. 전체 시안·생성기·렌더 캐시·과거 작업본은 포함하지 않는다. verification의 생성기 경로/해시는 생성 당시 문맥이며, 이 선별 패키지를 완전한 생성기 재현환경으로 주장하지 않는다. 현재 atlas와 참조 원본/rig/의존해시는 게시 후보에서 대조했다.

관련30검사와 runtime/Combat 빌드·구문검사는 통과했다. 실제 브라우저/모바일 시각·성능 검수나 배포는 수행하지 않았다. 독립 행동 readiness를 올리지 않는다.
