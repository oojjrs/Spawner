# 중립 사망음 청음용 스케치 18종

사용자가 외부에서 듣고 판단할 수 있도록 게시를 허락한 기존 WAV 후보다. **청음·품질 미검증, 애셋 승인 아님, 게임에 연결하지 않음.** 새 음원은 만들지 않았다.

표준 DSP로 합성한 재질·볼륨 윤곽 비교용 스케치이며 실제 동물/폴리 녹음이나 고품질 생성 도구 출력이 아니다. 낮은 음량에서 평가한다. 부자연스러운 전자음·노이즈·클릭이나 부적합한 꼬리는 폐기 대상으로 판단해야 한다.

이 폴더에는 18개 WAV와 원래 manifest만 보존했다. WAV는 44.1kHz mono PCM16이며 PCM 본문의 SHA-256을 원래 manifest와 대조했다. manifest의 sha256은 WAV 전체 파일이 아닌 PCM 데이터 해시다. 접촉 시각은 임시값으로 실제 접촉 프레임 검증을 대신하지 않는다. 생성 스크립트·검토 HTML은 이 패키지에 포함하지 않았다.
