핵심
방향
  • 속성을 조합해 유닛 템플릿을 만들고 군락을 번성시키는 전략 게임이다.
  • 첫 화면은 개체 없이 둥지만 있으며 첫 생명체부터 직접 설계한다.
  • 이름 붙인 설계로 개체를 탄생시키고 채집·운반·방어를 관찰한다.
  • 개체 생산과 둥지 성장에 진화 포인트를 나눠 쓴다.
  • 외부 빌드 없는 단일 HTML에서 군락과 월드의 상호작용을 보여 준다.

핵심 루프
  • 둥지에서 속성 슬롯을 채우고 이름을 지어 첫 개체를 탄생시킨다.
  • 개체가 자율적으로 찾은 먹이를 둥지로 회수해 진화 포인트를 얻는다.
  • 저장된 템플릿으로 추가 생산하거나 새 설계를 만든다.
  • 실제 활동을 보고 설계를 수정하며 변경은 다음 탄생부터 적용한다.
  • 둥지를 성장시켜 슬롯과 포인트 보관량을 늘리고 군락을 확장한다.
플레이 감각
  • 첫 설계부터 유저가 관여하며 초기 병종은 미리 제공하지 않는다.
  • 이름·외형·능력으로 자신이 만든 설계와 실제 활동을 연결한다.
  • 부족한 설계도 허용하고 관찰 결과로 다음 설계를 개선하게 한다.
  • 초기 능력의 절대 효율보다 같은 제약에서의 상대적인 조합을 겨룬다.
  • 이동·먹이 회수·길 형성·전투의 결과를 관찰할 수 있게 표현한다.
시스템
세계와 객체

맵 디자인 열기

  • 10,000×10,000칸을 후보별 거리장·노이즈로 합성하며, 가장 가까운 후보에서 멀수록 이득·위험이 커진다.
  • 시작 둥지는 같은 등급·조건으로 대체로 떨어지되 근접 경쟁을 허용하며, 기본형의 안전한 첫 회수를 보장한다.
  • 여러 입지 등급의 격차는 미정이며, 후보·등급은 생성에만 쓰고 개체는 발견한 지형·자원으로 행동한다.
  • 위험은 지형에 겹쳐 띠·넓은 군락·조각난 군락으로 만들고, 먹이는 위험 내부·너머와 안전한 우회로에 배치한다.
  • 미정: 후보 수·간격·등급 수·격차·비율·영향 범위·정식 위험 생성 비율과 분가 정착 조건.
위험지역 생성 (초안·미적용)
  • 면적은 둥지·물·통행 불가 지형을 뺀 보행 지면 기준이며, 가장 가까운 둥지 후보의 외곽부터 거리를 잰다.
  • 위험 목표는 전체 20%로 포자 12%·가시 8%이며 중첩하지 않고, 안전권·연결로를 먼저 보장한다.
  • 위험 면적의 약함 60%·일반 35%·고강도 최대 5%를 배분하며, 12칸 이내는 위험을 두지 않는다.
  • 거리 12~22칸은 약한 위험만 최대 10%, 22~44칸은 약함·일반 25%, 44칸 밖은 최대 35%다.
  • 시작 먹이는 서로 다른 방향의 2~4칸에 50개·8~12칸에 100개이며, 후보 간 보장량을 중복 계산하지 않는다.
  • 안전 출구 2개와 폭 3칸의 주요 안전길을 두며, 주요 우회는 최단길 2배·추가 12칸 이내로 연결한다.
  • 선택 채집지 우회는 최단길 3배 이내이며, 고강도 먹이의 위험은 허용하되 다음 생활권의 필수 통로로 쓰지 않는다.
  • 포자는 넓은 군락·띠, 가시는 조각 군락 위주이며, 띠 통과 깊이는 4~6칸·고강도 핵 면적은 4~12칸이다.
위험지역 (초안)
  • 조정 초안·미적용: 포자 기본 피해는 약함 0.08·일반 0.24·고강도 0.8/초이며 체류 중 적용한다.
  • 가시는 이동·채집 접촉당 약함 0.12·일반 0.36·고강도 1.2의 기본 피해를 준다.
  • 이동－저항은 활성 위험에서 이속 ×2.2, 힘－저항은 피격 뒤 2 피해 방호·지속 6초·재사용 18초다.
  • 감각－저항은 위험 감지 시 포자 1초분 또는 첫 가시 접촉을 막고, 방호 유효 3초·재사용 18초다.
  • 저항－저항은 포자 1.5초 노출·가시 4회 접촉 뒤 피해를 추가 80% 줄이며, 안전지역 5초 뒤 해제한다.
탄생과 수명
  • 기본 개체는 탐색·채집·운반·전투를 모두 수행한다.
  • 탄생에는 진화 포인트만 쓰며 먹이로 자동 생산하지 않는다.
  • 탄생 비용은 속성 0~5개에 3·5·8·12·17·23점이다.
  • 개체는 탄생 설계·능력·성향을 유지하며, 세 성향을 낮음·보통·높음으로 표시한다.
  • 64시드·20분 축소 시험에서 2속성 최선은 저가에 29승35패였으며, 개인 성장·수명·사체 수치는 미정이다.
속성 슬롯
  • 슬롯은 둥지 레벨별 2·3·4·5칸이며 중복 장착과 빈 슬롯을 허용한다.
  • 기본 운반 2개·이속 1칸/초·시야 3칸·체력 12이며, 시너지 10종은 게임 코덱스에서 확인한다.
  • 힘은 운반 +2개·이동은 초당 +0.5칸·감각은 시야 반경 +2칸이다.
  • 저항은 슬롯당 환경 피해를 25%씩 곱셈 감소하며, 둥지에서 초당 체력 0.25를 회복한다.
  • 초안: 감각 중복은 탐색을 돕지만 혼합 군락 평균 수입이 낮고, 저항 중복은 연속 환경 노출 생존에 강하다.
진화 포인트와 자원
  • 안전·약한 위험 먹이는 개당 1점이며, 먹이·사체 포인트는 둥지 회수 때만 얻는다.
  • 시험판은 25점으로 시작하며 사체 가치는 탄생 비용의 절반과 운반 중인 먹이다.
  • 둥지는 4단계이며 슬롯·보관량·성장 비용과 속성 종류 목표는 아래 표를 따른다.
  • 꿀버섯은 칸당 50개로 고갈·향기·공용 길을 쓰며, 먹이 가치는 생성 때 고정되고 위험 통과로 바뀌지 않는다.
  • 미적용 초안은 일반 위험 1.5점/개·고강도 3점/개를 유지하며, 32시드·20분 원거리 이득은 +16.6점이다.

Idle

개인 월드는 브라우저에서 진행하며 다른 탭·월드 목록·종료 중에는 멈춘다.

표현·자산
화면 규칙
  • 캔버스는 가용 영역을 채우며, 기본 배율 144에서 시작하고 2~144 사이로 조절한다.
  • 저배율에서는 여러 셀을 묶어 그리되 지형 단계의 판정과 색은 유지한다.
  • 콩은 새싹을 포함해 칸 높이의 35%로 표시한다.
  • 좌표·배율·시간값은 숨기고, 마지막으로 연 월드는 목록 맨 위에 ‘최근 월드’로 표시한다.
  • 둥지는 5×5칸 안에서 Lv.1 씨앗 둥지·Lv.2 어린 꽃·Lv.3 기존 둥지·Lv.4 꽃 군락으로 자란다.

각 단계는 뿌리를 고정하고 7.8초 대기 뒤 꽃잎을 9.6초간 열고 닫으며, 안쪽 노란 부분만 빛난다.

시작 생명체 자산

정식 화면은 사용자가 선택한 이미지 생성 결과를 투명 스프라이트로 추출해 사용한다. 절차적 재현은 기준 자산과 디테일이 달라지므로 사용하지 않는다.

입력
  • 둥지 제목 옆에서 이름을 바꾸고 레벨·진화 포인트·게이지·성장을 확인한다.
  • 코덱스에서 속성·시너지·둥지 성장을 검색하고 링크와 이력으로 탐색한다.
  • 속성을 클릭해 중복 장착하고 오른쪽 위 ⓘ로 코덱스를 열며 닫으면 설계로 돌아온다.
  • 유닛 카드를 누르면 탄생하며 카드 안 설계 수정과 빈칸의 +로 설계한다.
  • 맵 이동은 드래그·WASD·방향키, 확대는 휠, 둥지 이전·다음은 PgUp·PgDn, 첫 둥지는 Home이다.
저장

월드·진행·개체 성향을 이 브라우저에 자동 저장하며 만료 기한은 없다.

백업 내보내기·가져오기와 기존 서버 저장 가져오기를 제공한다.

월드는 이름 확인 후 삭제하며 사이트 데이터 삭제에 대비해 백업을 보관한다.
