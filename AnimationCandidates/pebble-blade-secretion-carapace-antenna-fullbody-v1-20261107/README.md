# 몽돌 blade-secretion-carapace-antenna

기존 승인된 안테나의 U자 감지 홈과 기관별 외형을 유지한 전신 원화 애니메이션. 모든 포즈는 이미지 생성 도구로 그렸다. 포장 코드는 완성된 전신 프레임 추출·같은 비율 크기 조정·전신 위치 등록·인코딩만 하며 신체 파츠 합성은 없다.

각 동작은 512×512, 4열×2행, 8프레임이다. 검수용 WebP/GIF는 무한 반복하고 실제 액션 반복·시간·접지점은 publication-manifest.json에 있다. 분비 없는 형에는 원거리 공격이 없다. 채집 신규 제작은 제외했고 운반·투척은 기존 공용 매핑을 쓴다.

원화·패킹 연락판의 전신 포즈와 접지를 확인했고, 프레임 수·반복·투명도·셀 경계·파일 해시·공격 큐 시간을 검증했다. 실제 게임 브라우저 재생 검수는 별도 통합 단계에서 수행한다.
