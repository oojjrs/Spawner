# 포자버섯 채집형 대기·이동 V1

사용자 승인 완료. 승인된 시트와 해당 시트에서 만든 GIF를 원본 그대로 보관한다.

## 파일
- 대기: `spore-gather-idle-v1-sheet.png`, `spore-gather-idle-v1-preview.gif`, `spore-gather-idle-v1.json`
- 이동: `spore-gather-walk-v1-sheet.png`, `spore-gather-walk-v1-preview.gif`, `spore-gather-walk-v1.json`
- `verification.json`: 시트와 개별 프레임의 일치 여부, GIF 타이밍, 본체 연결성 검사 결과.
- 원화: `DesignAssets/Tribes/spore/ApprovedGatherV1/source.png` (저장소 루트 기준)

## 재생 규격
- 공통: 투명 PNG 시트, 512 × 512 프레임, 8열, 좌상단부터 행 우선 순서, 피벗 (256, 448), 제자리 반복.
- 대기: 64프레임 × 100ms = 6.4초. 4096 × 4096 시트. GIF는 동일 정지 프레임이 합쳐진 17프레임이며 총 재생 시간은 같다.
- 이동: 16프레임 × 70ms = 1.12초. 4096 × 1024 시트. GIF 16프레임.
- GIF의 어두운 배경은 검수용이다. 게임용 투명 이미지는 PNG 시트를 사용한다.

## 승인 원화와 동작
원화 전체를 하나의 연속 표면으로 변형하여 비례와 색을 유지했다. 팔·머리·다리를 분리한 부품은 사용하지 않는다. 대기는 기본형의 `idle-v8` 타이밍, 이동은 `walk-v2` 타이밍을 따른다. 이동 시 작은 발 두 개가 교대로 디디며 양옆의 넓은 채집기관은 몸과 붙어 유지된다.

## 검증과 반영 범위
- 총 80프레임에서 시트와 개별 출력 프레임이 일치한다.
- 두 GIF는 각각 승인된 시트에서 추출되었고 메타데이터의 총 재생 시간과 일치한다.
- 본체가 하나로 연결되며 프레임 가장자리 잘림이 없다.
- `Design.html`의 채집량 속성 중 포자버섯 칸에서 승인 원화, 대기, 이동을 확인할 수 있다.
- 게임 코드 연결과 배포는 이 변경에 포함되지 않는다.
