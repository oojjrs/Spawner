# 걸어가는 산: 연속 피부 접합 보행 v2

사용자 승인 완료. 승인 산출물 보존을 위해 게시하며 게임 적용·로직 변경은 하지 않는다. 자세한 승인 근거는 APPROVAL.md 참조. 중간 Experiments 및 probe 자료는 역사자료이고 승인 최종 애셋이 아니다.

## 검토 파일

- `world-speed-comparison.mp4`: 이전 접합 시안(왼쪽)과 이번 연속 피부 시안(오른쪽)의 6초 비교. 1280×800, 60fps, 1배속, 무음. 기존의 작은 표시 크기와 확대 보기를 함께 표시한다.
- `Frames/00.png` ~ `63.png`: 투명 640×640 개별 프레임.
- `walk-candidate.webp`: 64프레임, 8×8 배열, 5120×5120 무손실 아틀라스. 등록되지 않은 검토 파일이다.
- `join-inspection-0.png` ~ `3.png`: 전체 보행 주기의 접합 확대 확인표.
- `art-checks.json`: 현재 애셋의 연결성·접지·원화 보존 검사. 자연스러움에 대한 승인은 아니다.

## 변경 사항

각 다리에 기존의 연속된 다리·발 원화를 한 장씩 사용했다. 어깨와 엉덩이 쪽은 몸통 안의 고정점에 붙이고, 피부는 발 위쪽까지만 부드럽게 휘도록 했다. 발가락 부분은 변형하지 않는다. 몸통 안에 들어가는 부분은 기존 등껍질 가림층으로 덮는다.

이전의 서로 겹치는 다리 조각 사이 경계와 작은 돌기 대신 하나로 이어진 피부를 사용한다. 삼각형 메시 시험에서 생긴 가로 줄은 최종 결과에 사용하지 않았고, 매끈한 역변환 렌더로 교체했다. `Experiments/`, `render-core.mjs`, `experiment-svg-triangles.mjs`, `probe-*`는 중간 시험이며 최종 사용 대상이 아니다.

새 그림을 생성하지 않았다. `body-source.png`, `lower-paws-source.png`, `shell-occluder.png`는 앞선 시안의 파일을 변경 없이 복사했다. 정확한 기존 생성 이력은 `../mountain-attached-walk-20261106/`에 보존되어 있다.

## 유지한 내용

- 산·수정·얼굴·몸통 원화와 몸의 작은 상하 이동.
- 네 발의 위치 경로, 지지·공중 구간, 발의 각도, 위상차.
- 0.3칸/초, 1.12칸 표시 정규화, 약 1.3233초 보행 주기.
- 발가락 그림의 모양. 다리 윗부분만 연결을 위해 변형한다.

## 한계

긴 보폭에서 피부가 늘어나 보이는 느낌은 남아 있다. 고정 길이 뼈로 관절을 해석하는 방식이 아니라, 어깨 고정점과 발 사이를 연결하는 애셋용 연속 변형이다. 따라서 해부학적으로 완벽한 관절 운동이라는 주장은 하지 않는다.

영상은 오프라인 애셋 렌더이며 실제 게임 녹화가 아니다. 게임 재생, 출발·정지·회전 연결, 모바일 성능, 게임 로직은 검사하지 않았다. 사용자 시각 검토와 승인이 필요하다.

## 재현

저장소 루트에서 기존 설치된 Node·Sharp·FFmpeg를 사용한다.

1. `XDG_CACHE_HOME=/tmp/spawner-mountain-font-cache node tools/mountain-continuous-walk-v2-20261106/render.mjs`
2. `node tools/mountain-continuous-walk-v2-20261106/check-art.mjs`

최종 렌더는 `rig.mjs`의 연속 피부 좌표를 `raster-core.mjs`로 그린다. 어느 파일도 게임에서 가져오지 않는다. `runtime.json`은 기존 크기 정보를 보존한 참고 자료이며 새 등록 파일이 아니다.
