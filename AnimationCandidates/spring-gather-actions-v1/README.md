# 샘방울 채집형 승인 동작 V1

공격·피격·탄생·사망 모두 사용자 승인 완료. 시트와 GIF는 승인된 원본 그대로 보관한다.

## 재생 규격
- 공통: 투명 PNG, 512 × 512 프레임, 8열, 행 우선 순서, 피벗 (256, 448).
- 공격: 16프레임, 1000ms. 300ms 타격 시작, 60ms 유지.
- 피격: 14프레임, 880ms. 500ms 충격 유지 후 복귀.
- 탄생: 13프레임, 1790ms. 530ms 분리, 790ms 착지. 둥지·배경을 제외한 몸체 시트다.
- 사망: 8프레임, 1440ms. 마지막 물웅덩이 자세를 유지한다.
- 각 동작은 단발 재생이며 검수 GIF만 반복한다. GIF의 어두운 배경은 검수용이다.

JSON의 durationsMs가 시트 타이밍이다. 공격 GIF는 10ms 단위 제약에 맞춰 누적 시간을 반올림한 gifDurationsMs를 사용하며, 총시간과 타격·유지 시각은 보존한다.

탄생의 세로 이동은 시트에 포함되어 있다. 게임에서 사용하는 둥지 위치와 연결 방식은 별도 적용이 필요하다. 이 변경에는 게임 코드 연결이나 배포가 포함되지 않는다.

기준 원화는 저장소 루트의 DesignAssets/Tribes/spring/ApprovedGatherV1/source.png다. 51프레임의 시트 일치, GIF 재생 시간·내용, 본체 연결성과 가장자리 잘림을 검사했다. 기획서의 샘방울 채집형에서 네 동작을 확인할 수 있다.
