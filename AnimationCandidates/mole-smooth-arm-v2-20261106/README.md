# 흙두더지 걷기 · 팔 연결 수정 시안

상태: 사용자 승인 (Sentinel_6116302f754c8191b2ee1a2545c8cd81). 게임 적용·푸시·배포 완료는 이 승인 기록에서 확인하지 않음. APPROVAL.md 참고.

## 수정

기존 원화와 편집 가능한 V1 가중치 메시를 재사용했다. 새 이미지를 생성하거나 차단된 생성 작업을 재시도하지 않았다.

이전 시험은 발톱을 강하게 고정하는 영역과 고정된 배 경계가 너무 가까워 팔이 접히고 찢어졌다. 팔·몸통 사이의 가중치 전이를 넓고 부드럽게 바꾸고, 갑작스러운 발톱 고정 영역을 없앴다. 얼굴 위쪽은 그대로 두고 아래 몸통이 팔의 이동을 조금 나눠 받도록 했다. 작은 뒷발은 별도의 짧은 보폭을 사용해 접합부 압축을 줄였다.

두 앞발이 교대로 뒤로 밀고, 들고, 앞으로 돌아온다. 원화에 보이는 두 앞발과 뒷발 하나만 사용한다. 보이지 않는 면이나 새 팔다리는 그리지 않았다. 64프레임이며 기존 V2와 같은 667ms를 검토용으로 사용했다. 이 값은 실제 게임 이동 속도 검증값이 아니다.

- 시각 표본 00·24·40·44·48·50·53·56·63에서 기존 팔 접힘·찢어짐 없음. 발톱의 큰 변형·분리 없음.

## 남은 한계

48~56번에서 배 아래가 당겨지고 가까운 팔이 약간 늘어나는 인상은 남는다. 원화의 기존 몸을 변형하는 방식이라 새로 그린 굽힘 자세와 같은 완성도를 주장하지 않는다. 정지 프레임과 연속성 검사를 한 시각 개선안이다. 실시간 영상 재생의 자연스러움, 게임 이동 접지, 시작·정지·방향 전환, 브라우저 재생은 검수하지 않았다.
