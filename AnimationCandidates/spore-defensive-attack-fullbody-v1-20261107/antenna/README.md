# 포자버섯 안테나 반격 공격

기본형 공격의 몸·갓 들이받기를 참고한 새 전신 공격입니다. 기존 승인 원화를 유지합니다.

- 16프레임, 4열, 512×512 셀, 1000ms, 비반복 동작. 검토용 GIF/WebP는 반복합니다.
- 타격: 300ms, zero-based frame 5. 기본형 타이밍을 그대로 사용합니다.
- 원거리, 새 기관, 신체 파츠 조립, 부위 워핑 없음.
- 기존 대기·이동·피격·탄생·사망은 변경하지 않는 추가 공격 패키지입니다.
- 전투 규칙·선제공격·반격 조건·능력치는 변경하지 않았습니다.
- publication-manifest.json에 실제 alpha16 기준점·최대축 크기·타이밍·해시가 있습니다.
- sources/는 이미지 생성 원본, prompt.json은 생성 프롬프트, qa/는 전 프레임 검토 자료입니다.
