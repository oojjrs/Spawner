# 포자버섯 칼날+분비+갑각+안테나 전신 애니메이션

- 기존 승인 원화 및 완성 복합형을 기준으로 제작했습니다. 안테나는 갓 아래 부채꼴 감각 주름입니다.
- 모든 신체 포즈는 이미지 생성으로 그린 완성 전신입니다. 신체 파츠 조립·부위 워핑 없음.
- 후처리는 셀 분리, 동작별 단일 균일 배율, 전신 위치 정렬뿐입니다. 탄생은 완성 전신의 강체 회전과 기존 둥지 장면을 사용합니다.
- 이 후보 패키지는 게임 코드/기획서/Git를 변경하지 않았습니다. 공유 등록은 통합 담당이 처리합니다.

## 동작
- idle: 16프레임, 6400ms, [512, 512] 셀, 4열
- walk: 16프레임, 1120ms, [512, 512] 셀, 4열
- attack: 16프레임, 900ms, [512, 512] 셀, 4열
- ranged-attack: 16프레임, 600ms, [512, 512] 셀, 4열
- hurt: 16프레임, 960ms, [512, 512] 셀, 4열
- death: 16프레임, 1440ms, [512, 512] 셀, 4열
- birth: 78프레임, 3120ms, [768, 512] 셀, 8열

## 적용
- 원거리는 분비형에만 존재하고 몸체만 포함합니다. 분리된 탄환은 없습니다. 발사 큐는230ms/frame5입니다.
- 근접은 칼날형에만 존재합니다. 타격 큐는400ms/frame7입니다.
- 없음은 기존 no image. 채집·운반·투척은 해당 공격/이동과 기존 자원 표현을 재사용하며 새 채집형을 만들지 않습니다.
- 일반 동작의 geometry는 첫 전신 프레임 alpha16 실측이며 referenceLength=max(폭,높이)입니다.
- 탄생 geometry는 전체 장면 속 마지막 유닛만 분리해 실측한 값으로 둥지를 제외합니다. 탄생 장면 위에 둥지·이동·회전을 중복하지 마세요.

## 검증
- 모든동작 다중프레임, 시트·GIF시간 일치, 불투명셀경계 잘림0, 일반동작 연결된 전신1개 검증.
- 탄생78×40ms,3.12초. GIF/WebP의 동일프레임 병합과 전체 재생시간을 검증했습니다.
- birth-body 마지막프레임은 idle0와 RGBA바이트 동일입니다.
- source/원화, sources/생성원본, qa/검토용 콘택트 시트, quality-report.json 포함.
