# 몽돌 carapace 반격용 몸통 공격

기본형 공격의 낮은 준비 자세, 오른쪽으로 몸을 돌리는 몸통 충돌, 복귀를 참고한 전신 원화 8프레임이다. 기존 외형을 유지했고 새로운 무기나 원거리 발사는 없다. 신체 파츠 합성 없이 완성된 프레임을 추출·균등 확대·접지 등록·인코딩했다.

publication-manifest.json에 프레임 시간, 충돌 프레임, 접지 기준점, 방향, 파일 해시가 있다. 미리보기 GIF/WebP는 무한 반복하고 런타임 공격은 1회다. 공격 자산 등록만으로 선공·추격·반격 발동 규칙을 바꾸지 않는다.

원화·패킹 전 프레임 육안 검수와 8개 고유 프레임·셀 경계·투명도·GIF/WebP 시간 및 무한 반복·SHA256·450ms 충돌 큐 검사를 통과했다. 실제 브라우저 재생은 이 제작 환경에서 검증하지 않았다.
