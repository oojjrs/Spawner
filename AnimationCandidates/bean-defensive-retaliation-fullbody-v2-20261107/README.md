# 새싹콩 반격 공격 연속성 수정 v2

실제 게임에 등록된 대기 프레임을 직접 기준으로 갑각·안테나 공격만 다시 제작했습니다. 갑각+안테나 v1은 이번 수정 대상이 아닙니다.

- 첫/마지막 시간 샘플은 실제 idle frame 0의 RGBA 픽셀과 일치합니다.
- 안테나: 768셀, pivot 383.5/654, referenceLength 333, 오른쪽. 접시 외에 머리잎이 없습니다.
- 갑각: 256셀, pivot 128/230, referenceLength 145, 왼쪽. 기존 작은 머리잎과 몸 비율을 따릅니다.
- 각 16샘플, 총 1000ms, 타격 300ms(frame index 5, pose 4) 유지. 원거리/발사체 없음.
- 완성 전신 그림만 사용하고 코드 파츠 조립은 없습니다. 공유 등록/전투 규칙/기획서/git은 변경하지 않았습니다.
