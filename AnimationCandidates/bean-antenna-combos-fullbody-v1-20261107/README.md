## 제작 및 시간 기준

모든 신규 몸체 포즈는 이미지 생성 도구로 하나의 연결된 전신 그림으로 제작했다. 코드는 완성된 전신 셀의 사각 자르기, 시트별 고정 균등 배율, 전신 위치 이동, 시트 포장만 수행한다. 신체 파츠 조합, 분리, 보간, 변형, 복제는 하지 않았다. 생성 자료와 프롬프트는 `Sources/`, `generation-jobs.json`, `generation-plan.json`에 보존했다. 사망 두 소스의 불필요 동작선은 이미지 생성 도구로 제거했다.

- 대기: 64샘플, 6,400ms, 실제 서로 다른 전신 8포즈.
- 이동: 24샘플, 960ms, 현행 새싹콩 단일 홉 동작. 전체 셀 이동으로 고정 홉 궤적을 적용했다.
- 근접: 16샘플, 1,000ms. 가장 뻗은 칼날 접촉 포즈는 350ms, 0-based frame6/pose4.
- 원거리: 24샘플, 600ms. 옆 분비구 열림/반동은 200ms, frame8/pose3. 꼭대기 안테나는 발사구가 아니다. 투사체/외부 효과는 시트에 없으며 기존 런타임 투사체를 연결한다.

## 기하와 검증

각 폼의 승인 neutral이 비탄생 첫 셀과 복귀 동작 마지막 셀에서 정확히 동일하며, 탄생 마지막 몸체도 동일하다. alpha16 neutral 전체 외곽의 긴 변을 referenceLength로 고정하고, 아래 8행의 alpha16 지지점 평균으로 pivotX를 기록했다. 모든 포즈의 경계에 맞춰 배율을 바꾸지 않는다. canonical core 204.8과 실측 전신 referenceLength를 구분했다.

탄생 런타임 pivot/referenceLength는 마지막 몸체의 변환된 지지점/기준 길이이며, 문서 전체 장면 pivot은 planningPivotX/Y로 별도 기록했다. 실제 최종 몸체 alpha16 연결요소 경계와 변환값 차이를 리샘플링 허용오차 안에서 확인했다. 원본 외형의 바이트 해시, 모든 PNG 시간셀과 생성 포즈의 정확한 픽셀 일치, 잘림 0, 모든 본체 셀의 유효 연결체 1개, WebP 전체 시간/루프/픽셀, GIF 총시간을 확인했다. GIF의 10ms 시간 단위로 인해 25ms 및 5ms 경계는 미리보기에서 양자화되며 PNG/JSON/WebP는 원래 시간을 유지한다.

기획서·게임·실험실·헤더 등록, git push와 배포는 통합 담당이 수행한다. 이 패키지 제작 단계에서 공용 코드나 문서를 수정하지 않았다.
