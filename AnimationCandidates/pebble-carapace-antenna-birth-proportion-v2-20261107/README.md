# 몽돌 갑각+안테나 탄생 끝포즈 비율 교정

8프레임 중 앞6프레임은 기존 픽셀을 그대로 보존했다. 마지막2프레임만 이미지 편집으로 전신 비율을 승인 대기에 맞췄다. 둥지의 외형·위치와 출구 방향은 유지했고 각 수정 프레임은 둥지를 포함한 완전한 장면이다. 신체 파츠나 몸체/둥지를 코드로 합성하지 않았다. 다른 동작과 기존 후보 폴더는 변경하지 않았다.

publication-manifest.json에 최종 몸체 기준점·길이·프레임 시간·파일 해시를 기록했다. qa-report.json에 몸체/대기 비율과 앞6프레임 보존, 둥지 왼쪽 영역 비교를 기록했다. 원본과 달리 마지막2장면 픽셀은 재작화 결과이며 바이트 동일하다는 뜻은 아니다. 브라우저 실재생 검수는 별도다.
