# 새싹콩 채집형 승인 공격·사망

2026-11-07 사용자 승인본이다. 공격 V3와 사망 V2의 시트·GIF 원본 바이트를 그대로 보존했다.

- 공격 V3: 512px 셀 16프레임, 고유 전신 자세 8개, 1000ms.
- 사망 V2: 512px 셀 16프레임, 고유 전신 자세 8개, 2260ms.
- 두 시트 크기: 4096×1024px. 투명 PNG에 전신 동작을 담았다.
- 몸·팔·손·접시를 함께 그린 전신 재작화다. 별도 파츠 합성을 사용하지 않았다.
- 첫 프레임은 승인 원화이며 공격 마지막 프레임도 같은 자세다.
- GIF는 시트 픽셀로부터 만들었고 밝은 검수 배경을 사용한다. 반복 정지 자세를 합쳐 GIF의 디코드 프레임 수는 공격 10개, 사망 8개이나 전체 시간은 JSON과 일치한다.
- 실제 동작은 1회 재생이고 검수 GIF만 반복 재생한다. JSON의 durationsMs와 framePoseIndices가 시트 각 칸의 시간과 자세 순서를 기록한다.
- 32프레임 원본 일치, GIF 재생성 바이트 일치, 잘림 없음, 8px 초과 연결체 1개, 기준 바닥 448px를 확인했다.

기획서 애셋 게시용이다. 게임 런타임 연결·적용·배포는 포함하지 않았다.
