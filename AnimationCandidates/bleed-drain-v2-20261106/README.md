# Bleed and drain V2 animated studies

Unapproved visual-only asset studies, generated using built-in imagegen from the previous V1 artwork. Sixteen distinct frames per effect, playback 12 fps, fixed cells; full sequence changes silhouettes and particle positions rather than scaling one keyart. Source sheets and extracted transparent 320px frames preserved. Review videos include normal speed and 0.4x, large and small neutral scale guides. No game code, integration, sound or deployment changed.

Bleed prompt: 4x4 sequential sprite sheet, staggered droplets appear, stretch, fall and fade, brief slash breaks apart. Drain prompt: crimson motes accelerate into fixed emerald core, absorb and dissipate. Drain white background was removed by a second built-in image edit.

Known limits: generated frame-to-frame contour variations; 12fps stylized cadence, not interpolated. No actual unit occlusion or game timing validation. Tiny low-alpha border glow remains in some cells. This is a revised animated approval candidate, not approved game integration.
