# 샘방울 칼날 + 분비 + 안테나

기존 승인 기관별 원화와 둥근 물갈고리 안테나를 바탕으로 제작한 전신 외형·동작이다. 신체 파츠 코드 조립 없이 각 셀을 image_gen으로 완성한 뒤 전체 셀 크롭·정수 정렬만 수행했다.

- idle: 16셀, 1920ms.
- walk: 16셀, 1120ms.
- melee: 16셀, 1000ms.
- ranged: 16셀, 600ms.
- hurt: 16셀, 800ms.
- birth: 16셀, 1790ms.
- death: 16셀, 1800ms.

시트 1920×1920, 셀 480×480. 대기·이동·공격·피격 마지막 셀은 첫 셀을 그대로 사용한다. 단발 동작 미리보기만 양끝 500ms 정지가 추가된다.

칼날이 있을 때만 근접을, 분비가 있을 때만 원거리를 제작했다. 원거리 본체에는 투사체를 굽지 않았다. 탄생은 둥지·낙하·착지가 포함된 전체 장면으로, 마지막 몸체 바닥 기준점을 기록했다. 중복 둥지나 추가 코드 이동을 붙이지 않는다.

publication-manifest.json이 게시·통합용 자료이며 모든 경로는 저장소 루트 기준이다. 동작별 pivotX/pivotY, alpha>=16 기준 max(width,height) referenceLength, registrationScale=1을 포함한다. 근접 접촉은300ms, 원거리 발사는200ms다. 없는 공격 메타데이터는 제공하지 않는다.

validate.py가 원본 RGBA 일치, 해시, 소스·시트 경계, 연결성, 타이밍을 재검증한다. 밝은·어두운 QA와 GIF/WebP 16프레임 디코딩을 검수했다. 코드로 신체 변형·중간 프레임 작화·파츠 회전·합성하지 않았다. 16키포즈 방식이며 60fps 독립 작화는 아니다. 공유 문서·게임 코드·Git·배포는 부모가 별도로 통합한다.
